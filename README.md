# depviz — визуализатор графа зависимостей apk

## Общее описание

CLI-инструмент на Python 3 (только стандартная библиотека), который строит
граф зависимостей пакета Alpine Linux (формат `apk`). Менеджеры пакетов и
сторонние библиотеки для получения зависимостей не используются: индекс
`APKINDEX.tar.gz` скачивается и разбирается самостоятельно.

## Функции и настройки

### Параметры командной строки

| Опция | Описание |
|-------|----------|
| `-p`, `--package` | имя анализируемого пакета (обязательная) |
| `-r`, `--repo` | URL репозитория или путь к файлу тестового репозитория (обязательная) |
| `-m`, `--repo-mode` | `remote` (по умолчанию) — реальный URL, `test` — файл тестового репозитория |
| `-d`, `--max-depth` | максимальная глубина анализа, целое >= 0 (по умолчанию 3) |
| `-f`, `--filter` | не учитывать пакеты, в имени которых есть эта подстрока |

На первом этапе при запуске все параметры выводятся в формате
`ключ: значение`. Ошибки (неверное имя пакета, не-http(s) URL, отсутствующий
файл, неверный режим, отрицательная или нецелая глубина, пакет совпадает с
фильтром) выводятся как `error: ...` с кодом возврата 2.

### Сбор данных (этап 2)

Для `--repo-mode remote` указывается каталог репозитория, например
`https://dl-cdn.alpinelinux.org/alpine/v3.20/main/x86_64`; к нему
добавляется `APKINDEX.tar.gz`. Архив скачивается через `urllib`, из него
читается файл `APKINDEX` (записи разделены пустой строкой, строки вида
`K:значение`; `P` — имя пакета, `D` — зависимости, `p` — что пакет
предоставляет).

Правила разрешения зависимостей:

* ограничения версий отбрасываются (`zlib>=1.0` -> `zlib`);
* виртуальные имена (`so:libz.so.1`, `cmd:sh`, `pc:...`) заменяются
  пакетом, который их предоставляет (поле `p`);
* конфликты (`!pkg`), зависимости на самого себя и имена, которых нет в
  индексе, пропускаются.

На этом этапе выводятся прямые зависимости пакета. Ошибки загрузки и
неизвестный пакет дают `error: ...` и код возврата 1.
